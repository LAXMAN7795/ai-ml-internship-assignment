# Task 2 – Retrieval-Augmented Generation (RAG) from Scratch

**Status:** Pending

## Objective

Build a Retrieval-Augmented Generation system from scratch using a public document collection containing at least 30 pages.

## Planned Implementation

- Document ingestion and text extraction.
- Text preprocessing and chunking.
- Embedding generation.
- Vector similarity retrieval.
- Retrieval evaluation using 15 manually written questions.
- Recall@5 comparison across two chunk sizes.
- Analysis of two retrieval failure cases.
- Explanation of BM25 and reranking.

## Implementation Constraint

Do not use LangChain or LlamaIndex.

## Deliverables

- Implementation notebook or Python source code.
- Document collection and source references.
- Evaluation dataset.
- Retrieval results and metrics.
- Failure analysis.
- Technical documentation.

**Final results will be added after implementation and evaluation.**
